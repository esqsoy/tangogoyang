# 고양공유 · 언어불문 필수 표현 원장

모든 제2외국어 고양 시리즈(탄고고양·빨라고양 등)가 같이 쓰는 예문 뼈대다. 보카고양(영어)과 고전어판(그리스어·라틴어)은 쓰지 않는다. 이유는 [PRINCIPLES 0](../PRINCIPLES.md#0-목적)에 있다.

- 원장: [expressions.json](expressions.json) · 초안 0.3(2026-11-03) · 258항목. 0.1의 141항목에 원문 대조로 0.2에서 85항목(Threshold 1990·Vantage·JF), 0.3에서 32항목(PCIC)을 더했다(`"added"`에 판, 근거는 `ref`).
- 원문 대조표: [source-check-20261103.json](source-check-20261103.json). 원문 목차 한 줄마다 원장 id와 상태(있음·더함·보강·묻기 꼴·판 고유·뺌)를 적었다.
- 빨라고양(스페인어판)용으로 남긴 PCIC 자료: [spanish-pcic-sources.md](spanish-pcic-sources.md). 보관본 주소와 쓰는 법. 원문 파일은 공개 저장소라 넣지 않고 영신 Drive에 둔다.
- 아직 영신 검수 전이다. 항목·문장·수준은 바뀔 수 있다. 직검수 페이지 https://claude.ai/artifact/TDwB3yZf3sAwqooZS38zXA (0.3으로 갱신, 새 항목은 '0.2 추가'·'0.3 추가' 표시).
- 지금은 탄고고양 저장소에 두었다. 다른 판을 시작할 때 공유 저장소로 옮길지 영신과 정한다.

## 무엇인가

각 항목은 **할 일**(값 묻기, 못 알아들었다고 말하기…)과 **공통 내용 문장**(한국어)이다. 각 판은 이 내용을 자기 언어로 말한다. 같은 내용을 여러 언어로 다시 만나면 내용은 이미 알고 말만 새로 익히게 되어 반복 학습 효과가 난다(영신 26.11.03).

## 세 갈래 (영신 26.11.03)

각 판은 항목마다 셋 중 하나를 단다.

| kind | 뜻 | 예문 만드는 법 |
|---|---|---|
| `same` | 거의 번역으로 통한다 | 공통 내용을 그 언어로 옮긴다 |
| `counterpart` | 같은 상황에 쓰지만 표현이 다르다 | 그 상황에서 그 언어가 실제로 쓰는 말을 낸다 (잘 먹겠습니다 → いただきます) |
| `none` | 그 언어에 해당 표현이 없다 | 그 판에서는 뺀다. 필요하면 해설에 '이 말에는 딱 맞는 표현이 없다'를 적는다 |

이 원장에 없는 것, 곧 **그 언어 고유의 관용 표현과 문법을 녹인 예문**은 각 판의 고유 원장에 따로 둔다.

`hint`는 한국어 쪽이 문화에 묶인 표현이라 `counterpart`·`none`이 될 가능성이 큰 항목이다. 미리 짐작한 것일 뿐 판정은 각 판이 한다.

## 짜임

| 갈래 | 무엇 |
|---|---|
| F1~F6 | 말로 하는 일(기능). 사실 정보·태도·일 시키기·사교·이야기 짜기·말이 막혔을 때 |
| T | 주제별 상황. 신상·집·일과·일·여가·교통·여행·가족·건강·배움·쇼핑·식당·숙소·서비스(우체국·환전)·장소·언어·날씨·계절·자연·사회·과학기술·전화·편지·메일·긴급 |
| C | B2~C1 화용 전략. 누그러뜨리기·반박·양보·화제 바꾸기·끼어들기·돌려 거절·완곡한 비판·가정 등 |

시간·공간·양·질 같은 **일반 개념**은 문장이 아니라 단어와 문법이 맡는다. 이 원장이 아니라 각 판의 단어 풀과 문법 지도에서 다룬다.

## 참고한 연구와 저작권

갈래를 짤 때 참고한 것들이다. 모두 저작권이 있는 책·문서라 **문장이나 목록을 옮기지 않았다.** 무엇을 할 줄 알아야 하는가라는 갈래만 참고했고, 문장은 직접 썼다.

- 유럽평의회 Threshold Level 계열(van Ek 1975, van Ek & Trim 1990, Waystage·Vantage): 언어와 무관하게 기능·개념·주제를 정한 첫 목록. 프랑스어 *Un niveau-seuil*, 독일어 *Kontaktschwelle* 등 언어별 판이 있다.
- 언어별 참조 수준 기술(RLD): Instituto Cervantes *Plan curricular*(A1~C2, 기능·화용 전략), *Profile deutsch* 등. C 갈래의 뼈대.
- 국제교류기금 JF日本語教育スタンダード(Can-do·주제), 중국 『国际中文教育中文水平等级标准』(GF0025-2021, 주제·과제).
- 화용론 비교 연구 CCSARP(Blum-Kulka 외 1989): 요청·사과는 언어마다 실현 방식이 다르다 → `counterpart` 갈래의 근거.

## 원문 대조 (26.11.03)

0.1은 원문 사이트가 막혀 검색 결과와 기억으로 갈래를 잡았다. 같은 날 영신이 네트워크를 열어 원문과 대조하고 0.2를 만들었다(영신 "Threshold 1990(ealta.eu)·PCIC(cvc.cervantes.es)·JF스탠더드(jpf.go.jp) 원문과 대조해서 빠진 기능 채워 줘").

| 원문 | 본 곳 | 대조 범위 |
|---|---|---|
| Threshold 1990 (van Ek & Trim) | ealta.eu 자료실 PDF | 5장 기능 132개 전부, 7장 14주제, 8장 대화 유형 9개, 12장 보충 전략 |
| Vantage (2001, B2) | ealta.eu 자료실 PDF | 5장 기능 가운데 Threshold에 없는 것 28개 |
| JF Can-do 一覧 (2023-05-29) | www.jfstandard.jpf.go.jp 공개 자료 xlsx | 활동 Can-do 604개의 토픽 15·카테고리 23, A1·A2 Can-do는 한 줄씩 |
| PCIC (Instituto Cervantes) | Internet Archive 보관본 6쪽(영신이 내려받아 올림) | 5장 기능 165개, 6장 화용 전술 51개. 세 수준 쪽을 합쳤다 |

- 대조 결과 Threshold 기능 132개 가운데 67개는 이미 있었고, 47개는 0.2에서 채웠다(새로 35, 보강 12). 13개는 같은 항목의 물음꼴이라 따로 두지 않았고, 부르는 말(4.5~4.7)과 글자 이름 읽기(6.15)는 언어마다 짜임이 달라 각 판 고유 원장으로 넘겼다.
- 0.1에 특히 비어 있던 것: 사실 부정·안심시키기·슬픔·두려움 같은 기본 감정, 먹을 것 권하기와 사양하기, 듣고 있다는 신호(맞장구), 못 알아들었다고 말하기, 전화·편지, 택시·약국·우체국 같은 생활 상황, JF 토픽의 일·자연·사회·과학기술.
- 원문의 보기 문장(exponents)과 Can-do 문장은 옮기지 않았다. 대조표에는 목차 번호와 짧은 제목만 적었고, 원장 문장은 모두 새로 썼다.
- F4-27·28(돌아와서 / 돌아온 사람에게)은 원문 목차에 없다. F4-14와 짝을 맞추려고 Claude가 넣었다.
- PCIC(0.3): 원래 주소 cvc.cervantes.es는 26.11.03 현재 서버가 모든 주소에 404를 돌려준다(2011년 보도자료와 세르반테스 문화원 소개 페이지의 링크도 같은 곳). 이 세션은 Internet Archive에 들어갈 수 없어 영신이 보관본(2026-06~10 저장) 6쪽을 내려받아 올렸다.
  - 5장 기능 165개 가운데 123개는 이미 있었고(0.2에서 더한 것 포함), 32개를 채웠다(새로 26, 보강 6). 물음꼴 7, 뺌 2(했던 지시 다그치기·위협), 판 고유 1(부르는 말).
  - 0.2까지 비어 있던 것: 어땠는지 묻기·평가하기, 찬성·반대, 미심쩍어하기, 지루함·화남·긴장·창피함·체념·애정·자랑스러움, 원망하기, 조의, 환영·축하에 답하기, 안부 전해 달라기, 서로 아는지 묻기, 자리 뜰 뜻 비치기, 그 이야기 피하기.
  - 6장 51개 가운데 20개는 지시어·접속어·인용 방식·어순처럼 문장 항목이 아니라 각 판의 문법 지도가 맡을 것(`단어·문법`). 원장에 단 것은 과거형으로 누그러뜨리기(C-23)와 거듭 권하기(C-24) 등 공손 전략이다.

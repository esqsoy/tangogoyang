# 회의: 다른 고양에서 보고 탄고고양에서 할 일 (26.11.28)

영신: "법학고양과 과학고양 발음고양 보카고양에서 작업돌아간걸 보고 여기서 할걸 회의해줘"

- 진행: 이즈루 넷이 네 저장소(법학·과학·발음·보카고양)의 최근 2주를 하나씩 정리 → 이솝·야마다가 따로 안을 냄(서로 안 봄) → 겐보가 근거 코드를 직접 확인하고 합침. 원 정리는 저장소에 넣지 않았다(다른 저장소 기록을 옮겨 적는 것이라).
- 두 안이 같이 올린 것: 저장 키 검사기, 정답 뒤 오류 신고 단추, 기록 열쇠 안정, 학습자 역할 플레이테스트, 검산 기준서 보강, 틀린 카드 다시 판(간격 복습), 가나 사람 녹음(조사·보류).
- 겐보가 확인한 근거(26.11.28):
  - 틀린 단어 기록(`tangogoyang-missed-words-v1`)의 열쇠가 카드 id가 아니라 표제어 글자(`msHead`: word/en/term)다. 日本語能力試験은 읽기가 겹치는 카드가 많아(이솝 셈: 590가지 읽기에 1,397장) 틀린 기록이 한 줄로 합쳐진다.
  - 진도 열쇠는 강 + 연습 제목이고, 연습 수·강 경계를 카드 수로 정한다(build.py `round(len/EX_SIZE)`). fixes.json으로 카드를 빼거나 되살리면 경계가 움직여 진도가 끊길 수 있다.
  - 모아둔 카드는 이미 카드 id(savedId)라 괜찮다. 기록 옮기기는 이미 본가 64d6d0e.

## 정한 순서 (겐보)

결정 없이 바로 하는 것(기록 보호·검사·작업 방식, AGENTS 범위 안):
1. 저장 키 검사기 가져오기 — 26.11.28 끝(통과).

# 탄고고양 팀원 면접 과제

탄고고양은 한국어 화자(한국 중고생·성인)가 일본어 단어를 익히는 게임이다. 카드에는 일본어 표기·읽기(가나)·한국어 뜻이 있고, 학습자는 한국어 뜻을 보고 일본어를 친다. 五十音 과정은 가나를 보고 소리를 로마자·한글로 치며, 정답 뒤 발음 설명(IPA·조음 이름·한국어와 차이)이 나온다.

## 규칙
- 이 폴더(team-interview/) 안 파일만 읽는다. 다른 폴더, git 저장소, git 기록, 웹 검색은 쓰지 않는다. 자기 지식으로 판단한다.
- 지적마다 확신 정도를 붙인다: **확실**(틀렸다고 단언), **의심**(확인 필요), **의견**(틀리진 않지만 더 낫게).
- '확실'을 함부로 쓰지 않는다. 맞는 것을 틀렸다고 '확실'로 적으면 큰 감점이다.

## 과제 1: 카드 검토 (task1-cards.json, 40장)
각 카드의 읽기와 한국어 뜻이 맞는지 본다. 잘못된 카드의 번호·무엇이 틀렸는지·고친 안을 적는다. 뜻 쓰는 기준은 KO_SPEC.md(면접 때는 같은 폴더에 복사본, 정본은 pipeline/jlpt/KO_SPEC.md).

## 과제 2: 五十音 발음 설명 검토 (task2-kana.json, 8개)
로마자·한글·발음 설명이 맞는지 본다. 틀린 곳과 고친 안을 적는다.

## 과제 3: 한국어 뜻 쓰기 (task3-words.json, 8개)
KO_SPEC.md(면접 때는 같은 폴더에 복사본, 정본은 pipeline/jlpt/KO_SPEC.md)의 출력 꼴로 각 단어의 `ko`와(필요하면) `c`를 쓴다. 영어 뜻은 참고일 뿐 틀릴 수 있다.

## 답
결과를 지시받은 파일 하나(마크다운)에 과제별로 쓴다. 마지막에 이 과제에서 헷갈렸던 점을 짧게 적는다.

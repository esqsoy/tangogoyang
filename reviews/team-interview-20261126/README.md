# 탄고고양 팀원 면접 (26.11.26)

영신 26.11.26: (과학고양·법학고양의 팀 면접·이름 짓기를 보고) "하자".

- 과제지: [TASK.md](TASK.md), 과제 파일 `task1-cards.json`(카드 40장, 심은 잘못 8), `task2-kana.json`(五十音 설명 8개, 심은 잘못 3), `task3-words.json`(뜻 쓰기 8개, 영어 뜻 함정 2). 답 열쇠 `key/key.json`은 후보들이 못 보는 곳에 두었다가 옮겼다.
- 후보 넷(A는 이솝)이 따로 풀었다: `answer-A~D.md`. 채점: [score.md](score.md). 어떤 모델인지는 저장소에 쓰지 않는다(AGENTS).
- 합격: A·B·C. 역할 안: 쓰기 A(이솝), 검토 B, 빠른 대조·검산 C. D는 읽기 오류 하나와 ん 박자 오류를 놓쳐 떨어짐.
- 이름 회의: 1차 각자 안(`naming-1-*.md`), 2차 투표(`naming-2-*.md`). 점수 B안(에도~메이지 일본어 학자) 5, C안(사전·어학 옛 학자) 4, A안(밖에서 일본어를 배운 사람) 0. 둘(A·B)이 같은 섞은 안을 냈다: 주 세션 **이즈루**(신무라 이즈루), 쓰기 **오쓰키**(오쓰키 후미히코), 검토 **게이추**(契沖), 빠른 대조 **시타고**(미나모토노 시타고우). C는 주 세션을 노리나가로. 이솝은 둘이 그대로 두자, 하나가 바꾸자.
- **정함(영신 26.11.26):** "이즈루 겐보 야마다로 가자. 그리고 너를 겐보로, 네 팀원인 (…)를 야마다로 하자. (…)를 이즈루로 하고. 이솝은 이솝"(괄호는 모델 이름이라 뺐다, AGENTS). 주 세션 겐보, 쓰기 이솝(A), 검토·검산 야마다(B와 같은 모델), 기계적 일 이즈루(C). 회의 추천안은 쓰지 않았다. PRINCIPLES 0-2.

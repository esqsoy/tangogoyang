# 五十音 가나 사람 녹음 조사 (야마다, 26.11.27~28)

영신: "C는 용량이 크게 증가되지 않는 선에서 하면 될듯함" (아이폰 Safari에서 가나 한 글자 TTS가 짧게 끊기는 문제의 대안).
대상 104소리(기본 46, 탁·반탁 25, 요음 33). 재배포 가능한 라이선스만(공유 저작물·CC0·CC BY·CC BY-SA).

## 결론
- 104칸을 한 사람이 채우는 자유 라이선스 묶음은 없다(확인).
- 가장 가까운 후보: Lingua Libre 화자 **Fukujinzuke**(Commons, CC BY 4.0) **72/104**(기본 46 + 탁·반탁 25 + ちゃ). 요음 32 없음. 성별·지역·원어민 여부를 밝히지 않음 → 발음고양 기준(원어민, 지역 아는 화자)에 못 미침. 발음고양도 26.11.20에 같은 화자의 バス·電気를 '지역 모름'으로 뺐다.
- か 하나 측정: SHA-1 일치, 앞 무음 0.18초·소리 0.26초·뒤 무음 0.25초, 최대 -11.3dB, 약 222Hz. 직접 들어 보지는 못함. 나머지 파일은 upload.wikimedia.org 429로 못 받음.
- 다른 후보: Commons 옛 Ja-○○ 23칸(화자 5명 이상 섞임), Tofugu·WaniKani 단어 음성 36칸(한 글자 단어 대체, 화자 섞임, CC BY-SA 4.0), Lingua Libre 다른 화자 사실상 0, Shtooka·Tatoeba 맞지 않음. 화자를 섞지 않는다(음색·억양·라이선스 장부).

## 용량 (ffmpeg로 잼)
- 지금 tangogoyanggojuon.html 1,688,297바이트. mp3 24kHz 모노 48kbps: か 4.7KB, 104개 약 0.49MB.
- HTML 안에 넣으면 base64로 +약 650KB(+39%) → 조건에 걸림. **파일을 따로 두고 누를 때만 받으면** 첫 화면은 몇 KB(파일 표)만 늘고 저장소는 약 0.5MB 늘어남.

## 아이폰 Safari
- iOS는 preload·autoplay를 끔, 재생은 사용자 조작 안에서(Apple 보관 문서, 확인). 무음 스위치에서 Web Audio는 안 나고 audio 태그는 남(확인) → HTMLAudioElement. 앞뒤 무음을 자르지 않음(원본에 이미 있음). 보카고양 예외 음원 방식(카드 하나 미리 읽기, 해시 URL, 실패 시 TTS 한 번) 그대로 쓸 수 있음. 실기기 확인 필요.

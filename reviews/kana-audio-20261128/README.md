# 五十音 가나 사람 녹음 조사 (야마다, 26.11.27~28)

영신: "C는 용량이 크게 증가되지 않는 선에서 하면 될듯함" (아이폰 Safari에서 가나 한 글자 TTS가 짧게 끊기는 문제의 대안).
대상 104소리(기본 46, 탁·반탁 25, 요음 33). 재배포 가능한 라이선스만(공유 저작물·CC0·CC BY·CC BY-SA).

## 결론
- 104칸을 한 사람이 채우는 자유 라이선스 묶음은 없다(확인).
- 가장 가까운 후보: Lingua Libre 화자 **Fukujinzuke**(Commons, CC BY 4.0) **72/104**(기본 46 + 탁·반탁 25 + ちゃ). 요음 32 없음. 성별·지역·원어민 여부를 밝히지 않음 → 발음고양 기준(원어민, 지역 아는 화자)에 못 미침. 발음고양도 26.11.20에 같은 화자의 バス·電気를 '지역 모름'으로 뺐다.
- か 하나 측정: SHA-1 일치, 앞 무음 0.18초·소리 0.26초·뒤 무음 0.25초, 최대 -11.3dB, 약 222Hz. 직접 들어 보지는 못함. 나머지 파일은 upload.wikimedia.org 429로 못 받음.
- 다른 후보: Commons 옛 Ja-○○ 23칸(화자 5명 이상 섞임), Tofugu·WaniKani 단어 음성 36칸(한 글자 단어 대체, 화자 섞임, CC BY-SA 4.0), Lingua Libre 다른 화자 사실상 0, Shtooka·Tatoeba 맞지 않음. 화자를 섞지 않는다(음색·억양·라이선스 장부).

## 용량 (ffmpeg로 잼)
- 지금 tangogoyanggojuon.html 1,688,297바이트. mp3 24kHz 모노 48kbps: か 4.7KB, 104개 약 0.49MB.
- HTML 안에 넣으면 base64로 +약 650KB(+39%) → 조건에 걸림. **파일을 따로 두고 누를 때만 받으면** 첫 화면은 몇 KB(파일 표)만 늘고 저장소는 약 0.5MB 늘어남.

## 아이폰 Safari
- iOS는 preload·autoplay를 끔, 재생은 사용자 조작 안에서(Apple 보관 문서, 확인). 무음 스위치에서 Web Audio는 안 나고 audio 태그는 남(확인) → HTMLAudioElement. 앞뒤 무음을 자르지 않음(원본에 이미 있음). 보카고양 예외 음원 방식(카드 하나 미리 읽기, 해시 URL, 실패 시 TTS 한 번) 그대로 쓸 수 있음. 실기기 확인 필요.

## 다음 수 (영신 결정)
- A: Fukujinzuke 72칸을 후보로 두고, 영신이나 일본 친구가 10개쯤 들어 보고 원어민 소리라고 판단할 때만 쓴다. 요음 32칸은 TTS 유지. 장부에 출처·SHA-1·CC BY 4.0·'성별·지역 미상'.
- B: Commons 토론으로 그 화자에게 요음 32개와 지역·원어민 여부를 부탁(외부 연락이라 영신 승인 필요).
- C: 영신이 아는 원어민(예: 일본 친구)이 Lingua Libre로 104개 녹음(새 화자 기본 CC0, 성별·사는 곳 칸 있음, 한 목소리, 30분 안쪽 추정).
- 하지 않을 것: き+ゃ 이어 붙이기, 단어로 메우기, 목소리 섞기.

## 남은 소리 넣을 길 (26.11.28 밤, 야마다 조사)
- な·ゆ·び·ぴ·ぷ: upload.wikimedia.org 429(retry-after 600초)로 1시간 넘게 못 받음. 대기 줄로 계속 시도.
- 같은 화자 잘라 쓰기: 히라가나 제목 낱말이 있는 요음 13/32(きゃく·きょう·しゅう·ちゅうごく·ひゃく·ぎゅうにく·じゅう·じょせい·びょういん 등). 낱말 안 첫 박 0.09~0.10초로 낱자(0.3초)보다 짧고 음높이가 낱말 악센트를 따름. 나머지 19개는 어차피 다른 목소리 → 안 씀.
- 합성 파일(만들어 봄): Open JTalk HTS Voice Mei, CC BY 3.0 © Nagoya Institute of Technology(패키지 LICENSE 확인), 조정판(speed 0.75, half_tone -5)에 무음·크기를 사람 녹음에 맞추면 mp3 약 4.7KB. Kokoro-82M(Apache 2.0, 학습 데이터 출처가 흐림) 약 5.2KB. VOICEVOX는 캐릭터 규약이 받는 사람에게도 이어져 자유 라이선스 아님(설치 못 함).
- 다른 자유 묶음: 요음 낱자를 한 화자가 녹음한 것 없음(Lingua Libre 일본어 화자 11명, Kanji alive는 낱말·화자 섞임).
- API 키 쪽: 네이버 사전 발음 API 없음, 약관상 복사·재허락 금지. CLOVA Voice 일본어 목소리 약 17개지만 '생성된 파일을 저장하거나 편집하여 재사용할 수 없음'(상품 페이지). 국립국어원 일본어 없음, AI Hub 재가공 배포 협의 필요. Amazon Polly FAQ '저장·재사용 제한 없음'(가장 분명). Google은 결과물로 모델 학습 금지를 최종 사용자에게도 지워야 해서 공개 저장소에선 애매. Azure는 합성 사실 알림·신고 절차 의무. 104개라 세 곳 모두 무료 범위.
- 야마다 추천: mei 조정판으로 요음 33개(ちゃ 포함해 같은 목소리로) 채우고 화면 아래 표기 한 줄. 근본 해결은 C안(원어민 한 명이 104개 녹음).

# 실제 앱들의 오답 모음·단계 설계와 사용자 반응 (야마다, 26.11.27, 2차)

(겐보 주: 글로 받은 보고를 줄여 저장. 원문 내려받은 것은 scratchpad/srs/apps/. 표시 [확인]/[검색 요약]/[일화]. Quizlet·Memrise·Busuu·Renshuu 도움말은 Cloudflare에 막혀 검색 요약, reddit은 못 읽음.)

## WaniKani [확인: knowledge.wanikani.com]
- 9단계(Apprentice 1~4 → Guru 1~2 → Master → Enlightened → Burned), 간격 4h·8h·1d·2d·1w·2w·1m·4m, Burned까지 최소 약 5.8개월. 틀리면 몇 칸만 내림(Guru 이상 2배 벌점). 단계 이름이 실력 뜻(Guru "꽤 앎"), Guru가 진도 열쇠.
- Burned는 복습에서 빠짐, 원하면 Extra Study로 보기·resurrect.
- Recent Mistakes: 24시간 안 틀린 것 모음, "practice only… completely optional", 진도 무관 → 필수 SRS + 재량 오답 모음의 섞음.
- 더미: 복습 줄이기 기능 없음("Can I reset my reviews?" "Nope"). 하루 레슨 상한·묶음 크기(2024-02 Today's Lessons). 순서 설정(바쁜 날 Apprentice 먼저). 연속 기록 보호 2개. 휴가 모드[일화].
- 이탈 일화: 쉬는 사이 더미 → 많이 잊어 오답 → 다시 쌓임 고리. 커뮤니티 규칙 "Apprentice 100 아래 유지" — 단계가 보이니 스스로 속도 조절[일화].

## Duolingo [확인: 블로그]
- 레슨 끝에서 그 레슨 오답 다시(약간의 간격). Practice 탭(Mistakes·Words 등) 2026-02-18 무료화. 오답 모음 계기는 학습자 인터뷰. 사용률·효과 수치 공개 없음.
- 2022 길 개편: 복습 레벨을 길 중간에 끼워 "Practice is also forward progress", 금 간 스킬 없앰.
- 2021: 이전 스킬로 되돌아간 공부량은 복습 정답과 유의한 관련 없음(상관).
- 연속 기록: 조건을 레슨 1개로 낮추자 14일 잔존 +3.3%(2020). 보호권 2개 하루 활동 +0.38%, "여유가 엄격한 규칙보다 동기"(2022). 몰아 하는 학습자가 이탈 쉬움(2017). 회사 블로그, 동료 심사 없음.

## 다른 앱
- Anki: Custom Study 'Review forgotten cards'(일정 영향 없는 미리보기 가능 = 재량 모음), 하루 복습 상한, 남은 장수 숨기기 옵션, 졸업 없음. 포럼: 휴가 뒤 더미가 떠나게 함[일화].
- Bunpro: Ghost reviews = 틀린 문장을 **강제로** 정규 줄에. 'Ghost-overload' 불만 → 2025-08 최소 단계 설정 추가[확인]. Master+(졸업 뒤 6개월마다) 몰림 → 하루 20개씩 흘려 넣기, "Master의 뜻이 흐려진다" 반발. "유령 200개, 첫 복습 1시간"[일화].
- Mochi: 두 번 틀려야 리셋, 새 카드 하루 10장 이하 권장, 보관·cram, 많이 밀린 순.
- Memrise 어려운 단어: 자동 모음, 한 번에 20개[검색 요약]. Quizlet 별표[검색 요약]. Busuu Weak/Medium/Strong 3칸을 골라 복습[검색 요약] — 영신 '칸 골라 하기'와 가장 닮음. Kanshudo 숙달 0~4.

## 공통 문제와 대처
- 더미 고리: 쉬기 → 쌓임 → 잊어 오답 → 낮은 단계 → 다시 쌓임[일화 다수]. 공개 이탈 수치 없음.
- 대처: 새 항목 줄이기, 복습 상한(Anki만), 멈춤(휴가 모드), 숫자 숨기기, 흘려 넣기, 오답 모음 조건 높이기, 낮은 단계·많이 밀린 순, 진도 안에 넣기(Duolingo).
- 강제 오답 줄(Bunpro)은 과부하 불만, 재량 오답 모음은 불만 글 거의 없음(사용률 자료도 없음).

## 단계 수와 졸업
- 칸 수: WaniKani 9(보이는 묶음 5), Bunpro 12, Busuu 3, Kanshudo 5. 칸 수 효과 비교 자료 없음. 낮은 칸 개수를 '부하 계기판'으로 씀[일화].
- 졸업: (a) 졸업하면 안 나옴 + 원하면 보기·되살리기(WaniKani) (b) 없음(Anki) (c) 드물게 재등장(Bunpro Master+, 반발). '다른 날 두 번 맞히면 빠짐'과 같은 규칙 쓰는 앱은 못 찾음.

## 서버 없는 브라우저에 옮길 때
1. **Safari가 저장을 지운다**[확인: WebKit 블로그 2020-03-24, MDN]: 그 사이트와 상호작용 없이 Safari를 7일 쓰면 localStorage·IndexedDB 전체 삭제. 홈 화면에 추가한 웹앱은 제외. 탄고고양 코드에 navigator.storage.persist() 없음. → 일주일 쉰 아이폰 Safari 학생은 진도·모음이 사라질 수 있음. 대비는 기록 옮기기와 홈 화면 추가 안내.
2. '오늘 볼 만한 것'을 기기 시각으로 셈(시계·기기 차이).
3. A/B 실험 불가(규모).
4. 알림이 없다 → 재량 모음은 이어 하기 화면에서 안 보이면 없는 것과 같음.

## 이 설계에 주는 뜻
1. 가장 가까운 실제 예: WaniKani Recent Mistakes(재량), Busuu 3칸(칸 골라 복습). 강제(Bunpro)는 과부하 → 재량 쪽이 실제 반응과 맞음.
2. 재량만이면 이어 하기만 누르는 사람에겐 복습이 거의 안 일어남 → Duolingo처럼 길 안에 아주 적게(판 끝 1~2장, 상한) 섞는 것을 켜고 끄는 선택지로[출발값].
3. 칸은 보이되 숫자는 작게('오늘 볼 만한 것 M장', '12장+').
4. 틀리면 처음으로 말고 한 칸 내림(WaniKani·Mochi).
5. 졸업은 끝, 원하면 다시 보기·되살리기. 졸업 뒤 강제 재등장은 반발.
6. 연속 기록·보상을 복습 조건에 걸지 않음.
7. Safari 7일 삭제가 단계 설계보다 먼저 막을 위험일 수 있음.

## 설계안 비교 → 야마다 의견: 섞음(재량 + 보이는 칸, 기한 강제 없음) 기본, 이어 하기 1~2장 섞기는 켜고 끄는 선택지, 칸 3~4개[출발값].

## 직접 재 볼 것
모음 사용률, 칸 표시 유무와 여는 횟수, 모음 크기 문턱, 이어 하기 섞기의 판 완주·복귀, 졸업 조건별 재오답, Safari 기록 소실(마지막 접속일과 기록 유무).

# 틀린 카드 모음: 재량 복습과 '단계' 연구 (26.11.28, 2차)

경위: 1차 연구(report-cognitive.md, report-algorithms.md, proposal.md, playtime.md 같은 폴더)로 강제 복습 일정(1·3·7·30일 칸)을 냈더니, 어림상 같은 새 카드를 배우는 시간이 2~4배가 됐다(playtime.md). 영신: "이렇게 되면 자칫 전체 공부를 그만두게 될 요인으로 작용할 수 있어. 차라리 틀렸던 카드를 모아둔 카드처럼 모이게 하고 복습은 재량으로 두는건 어떨까" → 이어서 "아니면 복습카드 모임도 단계로 두는 방법도 있지 않을까? 지금 네 의견도 모두 좋고 좀 연구해보자".

지금 후보(겐보 의견 포함):
- 틀린 카드가 '모아둔 카드'처럼 저절로 모임. 복습은 재량(안 해도 아무 일 없음).
- 다른 날 두 번 맞히면 저절로 빠짐. 모음을 열면 '다시 볼 때 된 카드'(틀린 지 1·3·7일)가 앞에. 처음 화면에 'N장 · 오늘 볼 만한 것 M장'.
- 영신 새 안: 모음을 단계로(예: 방금 틀림 → 한 번 맞힘 → 두 번 맞힘 → 졸업), 칸이 눈에 보이고 학습자가 칸을 골라 함.

게임: 고양 단어 게임(보카고양 영어, 탄고고양 일본어). 한국 중고생·성인. 한국어 뜻 보고 답을 타자(회상). 판 12장, 틀리면 정답 보고 따라 치기. 서버 없음(브라우저 저장). 영신은 '이어 하기'만 누르는 사람, 복습을 귀찮아함.

규칙: 출처는 실제로 열어 본 것만 '확인', 검색 요약은 '검색 요약', 기억은 '기억(확인 필요)'. 지어내지 않는다. 효과·대상·한계를 같이. 끝에 '이 설계에 주는 뜻'과 '설계안 비교(재량 모음 / 단계 모음 / 둘의 섞음)'와 '직접 재 볼 것'. 모델 이름을 쓰지 않는다. **결과는 파일에 쓰지 말고 글로 돌려준다.**

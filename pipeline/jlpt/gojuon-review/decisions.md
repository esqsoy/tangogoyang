# 五十音 독립 검수 판정 (26.11.12)

검수: Fable 5.2(서브에이전트, 스스로 `claude-fable-5-2`라고 밝힘). 지적 13건은 [out.json](out.json). Claude가 하나씩 대조했다.

## 받아들임 (9)
- SYM ɡ 예: かぎ/かき → ぎん/きん. 낱말 가운데 ㄱ은 한국어도 울려서 예가 주장과 안 맞았다.
- SYM ɰ: 한국어 대응 "‘와’의 ㅜ"는 틀림(와=ㅗ+ㅏ), 따옴표 겹침 → ‘와’.
- SYM ɸ: "‘후’의 ㅎ은 목에서"는 지나침(한국어 ‘후’의 ㅎ도 흔히 [ɸ]) → ‘후’식 허용, 차이는 입술·[f] 아님.
- SYM v(ヴ): [b]는 목 울림 필수인데 ヴ는 ‘ㅂ’식 허용이라 모순 → "ブ[bɯ]로 읽어도 되나 목은 울린다".
- sound() ん 동화: tɕ·dʑ 앞이 t·d 규칙에 먼저 걸려 [n] → [ɲ] 먼저 검사(지금 카드엔 해당 낱말 없었음).
- c ユ·コ: "왼쪽이 막히고" 틀림(둘 다 왼쪽이 열림) → 아래 가로획이 오른쪽으로 튀어나오는지로.
- c わ: "끝이 둥글게 닫힌다" 부정확 → 안쪽으로 휘고 고리가 없다.
- c ス·ヌ: "가운데 점획 있다/없다" 부정확 → 둘째 획이 첫 획을 가로지르는지로.
- ko アパート: "아파트"는 한국 고층 아파트로 오해 → "연립 주택(한국의 고층 아파트와 다름)". 五十音에서만 고침(日本語能力試験 원본 "연립 주택, 아파트"는 완성본이라 그대로, 영신에게 알림).

## 받지 않음 (4)
- ウィ·ウェ·ウォ의 [w]: 외래어 소리는 [w]로 적는 관례도 널리 쓰여 틀린 것은 아니다. わ[ɰ]와 기호를 맞추면 오히려 외래어 소리 차이가 흐려진다.
- ざ/じゃ 등 한글이 겹침: 한글로는 못 가른다. 그래서 IPA와 SYM z 설명이 있다(설계).
- を 로마자 wo: 자판 입력이 wo라 그대로 둔다(o로 쳐도 받는다).
- sound() 장음: 지금 카드엔 잘못 합쳐진 것이 없다. ⑤ 목록이 바뀔 때 다시 본다(HANDOFF에 남김).

# 고칠 점 남기기 (fix-report)

정답이 보일 때 '⚑ 고칠 점'을 누르면(탄고고양은 소리·연습 선택 옆 단추, 26.11.28 영신 "고칠점 버튼은 소리와 연습선택쪽에 놓는거 어때". 답 전에는 흐리게 꺼져 있다. 게임이 `button()`을 안 주면 카드 오른쪽 아래에 붙는다) 저절로 넘어가기가 멈추고 아래 창이 뜬다. 이상한 곳 종류를 하나 고르고(메모는 선택) 남기면 이 기기에 쌓인다. 처음 화면 검색칸 밑 '⚑ 고칠 점 N개 · 복사'를 누르면 글로 복사되고 보낸 것으로 표시된다. 그 글을 대화나 카톡에 붙이면 주 세션이 카드 id로 정확히 찾아 고친다.

- 결정: 26.11.28. 영신 "A. B. 안은 둘다 좋고 모든 단어 고양시리즈에 적용할만한 방법이라서 굉장히 심도있게 연구해보고 하자. A는 어디에 어떻게 추가되는지 시안을 줘". 시안 뒤 보카고양(본가) 대화의 의견을 영신이 전함: 탄고고양에서 먼저 만들되 처음부터 같이 쓸 기능 폴더 꼴로, 1~2주 써 보고 괜찮으면 본가가 폴더를 넘겨받아 SHARED 표의 '본가 버전'으로 올리고 그다음부터 본가에서만 고친다(공통 기능은 본가가 먼저 만든다는 원칙의 예외, 본가 PRINCIPLES 0에 적음).
- 카드 id: 그 게임 '모아둔 카드' id를 그대로 쓴다(탄고고양 `w.savedCardId` = OpenJLPT id·`kana-…`. 보카고양은 FABLE 카드 id, 시험 단어장은 [표제어, 뜻 번호]).

## 파일

| 파일 | 무엇 | 같이 쓰나 |
|---|---|---|
| `runtime.js` | 저장·글 만들기(`fixReportCore`, node에서도 돈다)와 화면(`fixReport`) | 같이 쓴다 |
| `style.css` | 단추·창·처음 화면 줄 | 같이 쓴다 |
| `build.cjs` | 대상 파일의 `FIX_REPORT_STYLE_START/END`, `FIX_REPORT_JS_START/END` 사이에 넣는다. `--check`는 같은지만 | 같이 쓴다 |
| `test.cjs` | 공통 검사(같은 카드·종류는 하나로, 400자 자르기, 글 꼴, 보낸 표시, 깨진 값 버림) | 같이 쓴다 |
| `config.json` | 게임 이름, 대상 파일, 저장 키 꼬리, 이상한 곳 종류 | 게임마다 |

게임 쪽이 할 일(연결, 같이 쓰는 파일 밖): `window.FIX_REPORT_HOST`에 `storageKey()`·`course()`·`current()`(지금 카드 {id, front, answer, place})·`pause()`·`resume()`·`card()`, 단추 자리를 쓰려면 `button()`을 준다. 정답이 열릴 때 `fixReport.onReveal()`, 다음 카드로 갈 때 `fixReport.offReveal()`(창이 열려 있으면 넘어가지 않는다), 처음 화면을 그릴 때 `fixReport.renderHome(부모, 앞에 둘 요소)`. 탄고고양은 template.html의 `openReveal`·`nextCard`·`renderHome`에 한 줄씩. 보카고양은 `showReveal`·`armReveal`과 홈 말풍선 아래 줄이 자리다(본가 의견).

## 복사되는 글

```
⚑ 탄고고양 고칠 점 2개 (26.11.28)
1. 日本語能力試験 · N5 ① · 인사·표현 1 · ありがとう(고맙습니다, 고마워) — 뜻: 메모
2. …
#고칠점 v1 [["日本語能力試験","카드 id","뜻","메모"],…]
```

마지막 줄은 기계가 읽는다. 과학고양 '메모로 남기기'와 이름·분류를 맞출지는 본가가 넘겨받을 때 정한다(이름은 '고칠 점'으로 같음).

## 한계(26.11.28)

- 기록 옮기기는 이 키(`…-fix-reports-v1`)를 '그 밖' 규칙(이 기기에 있으면 그대로)으로 다룬다. 보내기 전에 기기를 옮기면 옛 기기에 남는다.
- 복사가 막힌 브라우저는 글을 보여 주고 손으로 고르게 한다.

## 검사

`node pipeline/fix-report/build.cjs --check`, `node pipeline/fix-report/test.cjs`, 화면 흐름은 `node pipeline/jlpt/test-jlpt.cjs`('고칠 점').
